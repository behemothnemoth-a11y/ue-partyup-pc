# Contributing

Use Python 3.13 and the pinned requirements. Run `python -m unittest discover -s tests -v` before a pull request. Keep hardware results separate from mocked tests. Hardware acceptance is limited to the documented EVERBOOM pair.

Report app/Windows versions, speaker models and reproducible steps. Never attach raw phone bug reports, APKs, captures, device identifiers, credentials or unreviewed logs. Do not submit decompiled UE code or proprietary binaries.

Contributions are MIT licensed. Retain dependency notices. Do not add guessed commands, firmware/reset operations, automatic grouping or telemetry. Preserve active-group restrictions unless controlled hardware evidence supports a change.
