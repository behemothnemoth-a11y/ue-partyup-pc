# Privacy and local data

PartyUp PC requires no account and includes no telemetry, analytics, cloud playback, automatic updater or automatic diagnostic upload. Bluetooth control traffic is sent to the selected speakers. Source setup and builds download dependencies; the installed application does not need those downloads.

Saved speaker addresses, remembered identities, selections, EQ memories and seating stay under `%LOCALAPPDATA%/PartyUpPC/data`. Local bounded error logs are under `%LOCALAPPDATA%/PartyUpPC/logs`. The Help support-summary export omits speaker names and addresses and saves only where you choose. Review any diagnostic file before sharing it. Low-level developer diagnostics can contain device identifiers; do not post their raw output.

Closing the controller normally leaves speaker playback running. Uninstalling app files does not automatically delete your saved settings. To remove all local data, close the app and delete the PartyUpPC app-data folder deliberately.
